Built With Restraint

Everything you need to sing along.

Designed to feel native inside Spotify — fast to install, calm to read, and light on memory.

Standalone Liquid Glass Stage

Open a full frosted-glass lyrics overlay straight from Spotify's playbar with synced click-to-seek lines, adaptive album glow, and a static Low-RAM backdrop toggle.

100% Offline Pinyin Engine

Bundled pinyin-pro handles Mandarin transliteration locally with accurate tone marks and instant response — no external API keys or rate limits for Pinyin.

Dual & Pinyin-Only Modes

Read Hanzi + Pinyin side-by-side or switch to clean Pinyin Only across three tone styles (nǐ hǎo, ni3 hao3, ni hao), plus Spinyin Studio for manual lyrics.

Lightweight & Cross-Platform

Zero heavy WebGL shaders, near-zero CPU when the stage is closed, and clean one-line installers for Windows PowerShell, macOS, Linux, and Spicetify Marketplace.
